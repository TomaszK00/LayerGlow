# Release and OTA checklist

The active OTA manifest is at [`Software/update.json`](../Software/update.json) and currently points to the **v2.43 test candidate**. Archived **v2.16** remains unpromoted. **Keep the manifest format and path unchanged unless the updater firmware is updated too.**

## Preparing a new version

1. Build and test firmware on the supported ESP32 hardware.
2. Export the OTA-compatible `.bin` using the **same compatible partition and firmware layout** as existing deployed devices.
3. Name it consistently, e.g. `LayerGlow_v2_44_OTA.bin`.
4. Upload the binary to `Software/` *before* updating the manifest.
5. Compute the actual binary byte size and SHA-256 checksum.
6. Update `Software/update.json` with the new version, exact filename, byte size and lowercase SHA-256.
7. Verify the binary URL, checksum, update detection and actual OTA installation before announcing the release.
8. Update [CHANGELOG.md](../CHANGELOG.md); optionally create a GitHub Release with notes and checksums.

## Manifest format

```json
{
  "version": "2.43",
  "file": "LayerGlow_v2_43_OTA.bin",
  "size": 1749984,
  "sha256": "7fb51423def60d1d069c6e80dd6a10b667ab010c9990e0d41d86276bc6423ec0"
}
```

This is the manifest **as currently published**, not a proof that the binary was validated. Storing a higher version in `Software/archive/` does not activate it. Version 2.43 is explicitly a test candidate generated by GitHub Actions. Its build, size and checksum were checked, but installation and printer behavior still need hardware testing. For stable releases, validate the installation on hardware before marking a version stable. Keep older known-good firmware files available for recovery where appropriate.

## v2.43 compatibility

The manifest points only to `Software/LayerGlow_v2_43_OTA.bin`. The searchable FAQ includes the blue status LED patterns, and the web panel offers light, dark and system appearance modes. The mobile palette controls and selected effect label have been rearranged in this candidate. Older firmware using the historical repository URL or filename pattern may need a one-time manual OTA upload. Installation on physical hardware remains to be checked.
